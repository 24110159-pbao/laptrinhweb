# Customer product reviews

- Customers can create a review only for their own order item after both the order and shipment are marked delivered, including a recorded delivery time. The order item is pessimistically locked and `reviews.order_item_id` is unique, so concurrent submissions cannot create duplicate reviews.
- Customers can edit their existing review without changing its order item. Editing remains available if an order is later returned or refunded.
- Ratings are integers from 1 to 5, comments are optional and limited to 500 characters. Reviews are published immediately, and product averages/counts include all persisted published reviews.
- Review attachments are limited to five per review. Supported content types default to JPEG, PNG, WebP, MP4, WebM, and QuickTime; each file is limited to 20 MiB and videos to 60 seconds. Configure `REVIEWS_MEDIA_ALLOWED_TYPES`, `REVIEWS_MEDIA_MAX_FILE_SIZE_BYTES` (and the matching multipart limit `REVIEWS_MEDIA_MAX_FILE_SIZE`), and `REVIEWS_MEDIA_MAX_VIDEO_DURATION_SECONDS` to change these limits. The Spring multipart request limit defaults to 105 MiB and can be changed with `REVIEWS_MEDIA_MAX_REQUEST_SIZE`.
- Attachments are stored on Cloudinary. To accept any attachment, configure an enabled Cloudinary automatic moderation add-on with `REVIEWS_MEDIA_MODERATION` (for example `aws_rek`). Uploads fail closed when moderation is unset, pending, or rejected. Customers must also confirm that uploads comply with the site policy. Cloudinary moderation availability and supported formats depend on the account's enabled add-ons.
